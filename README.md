# 📚 Recipe Book App (Flutter)

A beautiful and simple **Recipe Book App built with Flutter** that allows users to explore different recipes with images, ingredients, and step-by-step cooking instructions in a clean and modern UI.

---

## 📸 Project Preview

![Recipe Book App](https://github.com/gillzaib021-code/Recipe-Book/blob/4a29593379f18f09d7a2553f53e8ecf121572252/recipe%20book.jpeg?raw=true)

---

## ✨ Features

- 🍽️ Display list of delicious recipes  
- 🖼️ Attractive recipe images UI  
- 📖 Detailed recipe screen (ingredients + instructions)  
- 🔍 Easy navigation between screens  
- 📱 Fully responsive Flutter UI  
- ⚡ Smooth and clean user experience  

---

## 🛠️ Technologies Used

- Flutter 💙  
- Dart 🎯  
- Material Design  

---

## 🚀 How to Run

git clone https://github.com/gillzaib021-code/Recipe-Book.git

cd Recipe-Book

flutter pub get

flutter run
